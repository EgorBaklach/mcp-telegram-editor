# Source Monitor Pipeline

## 1. Маршрутизация источников
Все источники описаны в `./references/<source>.md` (шаблон для новых — в [resources/template.md](./resources/template.md)):
* Если в запросе указан источник и файл `./references/<source>.md` существует — прочитай **только его** и выполни pipeline.
* Если источник не указан или не найден в `./references/` — прочитай и последовательно выполни pipeline для каждого файла в `./references/*.md`.

## 2. Порядок выполнения (для каждого источника)
1. **Обнаружение:** Вызови инструмент обнаружения из спецификации источника. Если `status == error` или список новых элементов пуст — кратко выведи статус и **немедленно заверши обработку источника** (без чтения кода проекта и отладки).
2. **Анализ и фильтрация:** Для каждого элемента проведи исследование/отбор строго по методу из спецификации источника. Если элемент не проходит фильтр — пропусти его согласно правилу источника.
3. **Подготовка материала:** Активируй указанный в спецификации скилл и подготовь текст по структуре источника.
4. **Доставка:** Отправь материал через инструмент доставки из спецификации.
5. **Фиксация:** После успешной доставки вызови инструмент фиксации из спецификации, чтобы исключить повторную обработку.
