# 📡 FL.ru — дайджест новых заказов

Мониторинг и оценка новых заказов на бирже FL.ru по профилю разработчика (MCP-сервер `mcp-telegram-editor`). Скилл `telegram_editor_strategy` для этого источника **не используется** — отправляются только короткие карточки-уведомления.

1. **Обнаружение:** инструмент `check_new_orders`.
   Поля каждого элемента в `new_orders`: `project_id`, `title`, `link`, `budget`, `description`.
2. **Анализ и фильтрация:** активируй скилл `developer-profile` и оцени процент совпадения каждого заказа (`0%..100%`) с компетенциями, стеком и проектами из профиля:
   * **Совпадение `< 50%`:** уведомление в Telegram **не отправляется** — сразу переходи к п.5 (`mark_order` с `published = false`).
   * **Совпадение `>= 50%`:** заказ проходит к отправке (п.3 → п.4 → п.5 с `published = true`).
3. **Подготовка материала:** короткий HTML-пост (без лонгридов):
   * **При совпадении `50%..74%`:**
     * Заголовок: `<b>💼 Новый заказ на FL.ru — совпадение {X}%</b>`
     * Название, бюджет, строка **«Рентабельность (1 500 ₽/ч):»** (🟢 *Выгодно* / 🟡 *Обсуждаемо* / 🔴 *Ниже ставки* с оценкой трудозатрат в часах), краткое пояснение (1–2 предложения, чем именно пересекается со стеком) и кликабельная ссылка `<a href="{link}">Открыть заказ на FL.ru</a>`.
   * **При совпадении `>= 75%`:**
     * Всё из пункта выше + блок **«Сопроводительное предложение»** в теге `<pre>...</pre>` (чистый текст без вложенных HTML-тегов для копирования в один клик в Telegram и отправки заказчику на бирже), составленное от первого лица на базе релевантных кейсов из `developer-profile`, примерной оценки сроков/стоимости из расчёта `1 500 ₽/ч` и контактов из `.agents/skills/developer-profile/.env`.
4. **Доставка:** инструмент `notify` (`message` = готовый короткий HTML-текст).
5. **Фиксация:** инструмент `mark_order` (`projectId` = `project_id`, `published` = `true` для опубликованных `>= 50%` или `false` для отклонённых `< 50%`).
