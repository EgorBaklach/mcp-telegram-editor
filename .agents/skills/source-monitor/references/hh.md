# 📡 HH.ru — дайджест новых вакансий

Мониторинг и оценка новых вакансий на HeadHunter (`hh.ru`) по профилю разработчика (MCP-сервер `mcp-telegram-editor`). Скилл `telegram_editor_strategy` для этого источника **не используется** — отправляются только короткие карточки-уведомления в личный чат с ботом.

1. **Обнаружение:** инструмент `check_new_vacancies`.
   Поля каждого элемента в `new_vacancies`: `vacancy_id`, `title`, `company`, `address`, `schedule`, `link`, `salary`, `description`.
2. **Анализ и фильтрация:** активируй скилл `developer-profile` и оцени процент совпадения каждой вакансии (`0%..100%`) с компетенциями, стеком и опытом из профиля (с учётом локации `address` и формата работы `schedule`):
   * **Совпадение `< 50%`:** уведомление в Telegram **не отправляется** — сразу переходи к п.5 (`mark_vacancy` с `published = false`).
   * **Совпадение `>= 50%`:** вакансия проходит к отправке (п.3 → п.4 → п.5 с `published = true`).
3. **Подготовка материала:** короткий HTML-пост (без лонгридов):
   * **При совпадении `50%..74%`:**
     * Заголовок: `<b>🏢 Новая вакансия на HH.ru — совпадение {X}%</b>` (если в `address` присутствует Екатеринбург, добавь метку `📍 Екатеринбург`).
     * Название, компания, локация (`address`), формат работы (`schedule`), вилка зарплаты (`salary`), строка **«Оценка оффера (от 150 000 ₽ / 1 500 ₽/ч):»** (🟢 *Выгодно* / 🟡 *Обсуждаемо* / 🔴 *Ниже ожиданий*), краткое пояснение (1–2 предложения, чем именно пересекается со стеком) и кликабельная ссылка `<a href="{link}">Открыть вакансию на HH.ru</a>`.
   * **При совпадении `>= 75%`:**
     * Всё из пункта выше + блок **«Сопроводительное письмо»** в теге `<pre>...</pre>` (чистый текст без вложенных HTML-тегов для копирования в один клик в Telegram и вставки при отклике на HH.ru), составленное от первого лица на базе релевантных кейсов из `developer-profile` и контактов из `.agents/skills/developer-profile/.env`.
4. **Доставка:** инструмент `notify` (`message` = готовый короткий HTML-текст).
5. **Фиксация:** инструмент `mark_vacancy` (`vacancyId` = `vacancy_id`, `published` = `true` для опубликованных `>= 50%` или `false` для отклонённых `< 50%`).
